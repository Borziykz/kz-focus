# KZ Focus Prototype

Минималистичный прототип KZ-игры на Godot 4: вид от первого лица, air-strafe, longjump, bhop, crouch и короткая тестовая трасса.

## Совместная разработка

Основная ветка — `main`. Новые изменения делаются в отдельных ветках и отправляются через Pull Request. Не коммитьте папку `.godot`, локальные сборки и пользовательские сохранения.

Музыкальный файл не хранится в репозитории. Для локальной музыки положите MP3 по пути `audio/background_music.mp3`.

## Запуск

1. Откройте Godot 4 Standard.
2. Нажмите **Import** и выберите `project.godot`.
3. Откройте проект и нажмите **F6/F5**.

## Управление

- WASD — движение
- Мышь — обзор
- Space или прокрутка колеса в любую сторону — прыжок
- Shift или C — приседание
- Q — поставить checkpoint
- E — вернуться на checkpoint
- R — рестарт всей трассы
- M — включить или выключить музыку
- F — прокрутить нож-бабочку
- ЛКМ — выполнить взмах ножом
- После выключения музыка при следующем включении начинается сначала
- N — включить/выключить noclip (Space вверх, Shift вниз)
- Z/X — предыдущий/следующий checkpoint
- Esc — меню паузы и настройки
- Esc — освободить мышь
